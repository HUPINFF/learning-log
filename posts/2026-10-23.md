### Python的协议的概念: 我们这里协议为了我好理解我比作Java的接口 ，

这里python的协议和java的接口都是不能实例化的
python协议类的__init__被换成了一个这季节抛异常的函数
Python中的**类**是如何加入协议的呢，要看这个类有没有实现某个协议中的方法，例子如下：

```python
from typing import Protocol, runtime_checkable

@runtime_checkable
class Speaker(Protocol):
    def speak(self) -> str: ...

class Dog:
    def speak(self) -> str:
        return "woof"

print(isinstance(Dog(), Speaker))   # True
Speaker()                            # TypeError

```

在Python的上下文管理器协议中，只要哪些类实现了__enter__和__exit__方法，就算加入了上下文管理器协议了，就可以使用with 类的实例化()：这种方法了
