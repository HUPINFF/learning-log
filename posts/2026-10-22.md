### os库的作用

os主要是与操作系统的交互，***管理文件与目录***, ***操作路径***， ***获取系统与环境信息***
```python
os.getcwd()  # 返回当前工作目录的绝对路径

os.chdir(path) # 把当前工作目录切换到path

os.mkdir(path)  #创建单级目录，父目录不存在会报错

os.makedirs(path,exist_ok = True) # 创建多级目录，exist_ok = True时目录存在也不报错

os.path.dirname(path)   #取路径的目录部分

os.path.join(a,c,...)   #按当前系统规则拼接路径(跨平台安全，自动处理分割符)

os.path.abspath(path)  #  返回绝对路径

os.path.getmtime(path)   #返回最后修改时间戳

os.path.getsize()  #返回文件大小

os.path.exists(path)  # 判断路径是否存在（文件目录都算）

__dir__  #是表示当前模块(.py)的路径
```

3. 调用LLM模型请求函数

```python
def call(sys_prompt, json_mode=False):
  kw = {}
  if json_mode:
    kw["response_format"] = {"type": "json_object"}
  r = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
      {"role": "system", "content": sys_prompt},
      {"role": "user", "content": JD},
    ],
    temperature=0,
    **kw,
  )
  return r.choices[0].message.content
```

4. 主线程调用：
```python
for name, p, jm in [
  ("v1 模糊", V1, False),
  ("v2 明确字段", V2, False),
  ("v3 明确+示例+json_mode", V3, True),
]:
  print("=" * 25, name, "=" * 25)
  raw = call(p, jm)
  print(raw)
  try:
    json.loads(raw)
    print("-> JSON 合法")
  except json.JSONDecodeError as e:
    print("-> JSON 解析失败:", e)
  print()

```
