## 卡在哪了

「每篇文章一个 md 文件」和「纯前端」是一对矛盾——浏览器没办法列出一个目录里有哪些文件。

本来准备写个 Python 脚本扫目录生成索引文件，后来发现 Vite 自带 `import.meta.glob`，构建的时候就把目录扫完了。

**一行 Python 没写，问题没了。** 以后新增文章只需要新建一个 md 文件。

## 今天搞懂的一个概念

`import.meta.glob` —— Vite 提供的构建期文件扫描。

```js
const files = import.meta.glob('../posts/*.md', {
  eager: true,
  query: '?raw',
  import: 'default',
})
```

它和 `import` 的区别在于：`import` 的路径必须是我写死在代码里的，而 `import.meta.glob` 接受通配符，**打包的时候**由 Vite 去遍历目录，把匹配到的文件全部塞进来。

关键词是「打包的时候」——浏览器运行时并没有读文件系统的能力，是构建工具提前把这件事做完了。
